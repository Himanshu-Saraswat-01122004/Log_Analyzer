## 🚀 Getting Started

### Prerequisites

- Node.js 16.x or higher
- npm or yarn

### Installation

<details open>
<summary><b>Step 1:</b> Clone the repository</summary>

```bash
git clone https://github.com/yourusername/log-analyzer-next.git
cd log-analyzer-next
```
</details>

<details open>
<summary><b>Step 2:</b> Install dependencies</summary>

```bash
npm install
# or
yarn install
```
</details>

<details open>
<summary><b>Step 3:</b> Start the development server</summary>

```bash
npm run dev
# or
yarn dev
```
</details>

<details open>
<summary><b>Step 4:</b> Open in browser</summary>
  
Open [http://localhost:3000](http://localhost:3000) in your browser.
</details>

## 📖 Usage

<div align="center">
  <img src="https://via.placeholder.com/600x300?text=Usage+Example" alt="Usage Example" width="80%" />
</div>

### 1️⃣ Upload a Log File

- Drag and drop a log file onto the upload area, or click to select a file
- Supported formats: Common log format (CLF), Combined log format, and custom formats

### 2️⃣ View Analysis

- After upload, the application automatically processes and displays the data
- Navigate between analysis tabs to explore different aspects of your log data

### 3️⃣ Filter Data

- Use the time filter to focus on specific time periods
- View data by user, URL, or other parameters depending on the active tab

### 4️⃣ Access Recent Files

- Previously analyzed files appear in the "Recent Files" section for quick access
- Click on any recent file to view its analysis again
